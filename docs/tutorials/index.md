# Tutorials

Charter: this directory holds **learning-oriented** pages. A tutorial takes you
from a cold start to a first working result, in order, with every step's
expected outcome stated. It assumes nothing about the codebase.

- [Your First Typio Session](getting-started.md) — install Typio, start the
  daemon, install an engine, and type with it in a real application.

When you already know what you want to achieve, use
[How-to Guides](../how-to/index.md) instead; for exact commands and keys, use
[Reference](../reference/index.md).
