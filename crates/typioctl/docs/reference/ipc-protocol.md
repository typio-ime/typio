# IPC Protocol Reference

The wire protocol is **TIP v1**. The authoritative reference lives with the
daemon:

- [Daemon IPC Protocol Reference](../../../../docs/reference/ipc-protocol.md)

`typioctl` is one of several possible TIP v1 clients; the daemon defines the
contract. See [CLI Reference](command.md) for the mapping from each `typioctl`
command to the underlying RPC.
