## Before submitting a PR

- [ ] Build succeeds from a clean tree (`cargo build -p typioctl`)
- [ ] Tests pass (`cargo test -p typioctl`)
- [ ] User-facing behavior is documented
- [ ] `CHANGELOG.md` is updated
